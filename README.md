# Gemini 4 Argon Explained

Google's Gemini 4 Argon introduces a major shift toward long-horizon AI workflows, with up to 1,000,000 output tokens, phased availability, new pricing, software engineering capabilities and a strong cybersecurity focus.

## Key Takeaways

- Gemini 4 Argon was announced by Google on September 30, 2026.
- Access is being rolled out in phases rather than opening broadly at launch.
- Introductory pricing starts at $2 per 1M input tokens and $10 per 1M output tokens.
- Google says the model supports up to 1,000,000 output tokens.
- The model is positioned for long-horizon AI workflows, software engineering and cybersecurity use cases.
- Benchmark figures referenced in this project are Google-published results, not independent Digital Pulse Brief testing.
